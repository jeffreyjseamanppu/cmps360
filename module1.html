Guided Learning Experience: Java, VS Code & GitHub

Estimated time: 60–90 minutes. Complete this lab before Assignment 1.

Part A: Install the Development Tools

Step 1 — Install VS Code. Download and install Visual Studio Code for your operating system.
Step 2 — Install the Java Development Kit. Install Eclipse Temurin JDK 25 LTS or the JDK version approved by your instructor.
Step 3 — Install Java extensions. Open VS Code → Extensions. Search for and install Extension Pack for Java by Microsoft.

Part B: Verify Installation

In VS Code, select Terminal → New Terminal and run:

java -version
javac -version

Both commands should return version information. If a command is not recognized, check the JDK installation, environment path, and restart VS Code.

Part C: Create Your First Program

Create and open a folder named CMPS360-Java-Module1. Add a file named HelloWorld.java:

public class HelloWorld {
    public static void main(String[] args) {
        System.out.println("Hello, CMPS 360!");
        System.out.println("Welcome to Java Programming.");
    }
}

Use VS Code's Run action or execute:

javac HelloWorld.java
java HelloWorld

Expected output:

Hello, CMPS 360!
Welcome to Java Programming.

Part D: Explain the Code

  • public class HelloWorld declares the class.
  • main() is the program entry point.
  • System.out.println() prints to the console.
  • javac compiles Java source into bytecode.
  • java runs the compiled program using the JVM.

Part E: Push Code to GitHub

  1. Create an account at GitHub and install Git.
  2. Confirm Git is available by running git --version.
  3. Create a new, empty repository named CMPS360-Java-Module1. Do not initialize it with a README or .gitignore on GitHub.
  4. In your local project folder, create a .gitignore file to exclude compiled files and generated folders:
*.class
bin/
out/
.vscode/

Then run the following commands, replacing YOUR_USERNAME with your own GitHub username:

git init
git branch -M main
git add .
git commit -m "Initial Java application"
git remote add origin https://github.com/YOUR_USERNAME/CMPS360-Java-Module1.git
git push -u origin main

Visit the GitHub repository in a browser and verify your source code appears. Make a change, then push the update:

git add .
git commit -m "Updated Java application"
git push

GitHub may prompt you to authenticate. Your GitHub account password is not used directly as a Git command-line password.

Assignment 1: Java Fundamentals and Console Programming

50 points · Week 1 · Individual

Scenario: Build a Student Information and Grade Calculator in Java using VS Code.

Requirements

  1. Create a class named StudentGradeCalculator.
  2. Display the student's name, major, and course name.
  3. Declare three numeric variables representing assignment grades.
  4. Calculate the average of the three grades.
  5. Use an if/else statement to determine whether the student passed (average ≥ 70).
  6. Display results with System.out.println().
  7. Include explanatory code comments.
  8. Run and test the application.
  9. Push the source code to GitHub.

Example Program

public class StudentGradeCalculator {
    public static void main(String[] args) {
        String studentName = "Jane Smith";
        String major = "Computer Science";
        String course = "CMPS 360";

        double grade1 = 85;
        double grade2 = 92;
        double grade3 = 88;

        double average = (grade1 + grade2 + grade3) / 3;

        System.out.println("Student: " + studentName);
        System.out.println("Major: " + major);
        System.out.println("Course: " + course);
        System.out.println("Average: " + average);

        if (average >= 70) {
            System.out.println("Status: Passed");
        } else {
            System.out.println("Status: Failed");
        }
    }
}

Important: Use the example as a reference, but create your own application with different student information and grades.

Assignment 2: Object-Oriented Java Application and GUI

50 points · Week 2 · Individual

Scenario: Develop a simple inventory application for a retail business. Store product information, calculate inventory value, and display results in the console and a dialog box.

Requirements

  1. Create a class named Product.
  2. Define at least three private attributes: name, price, and quantity.
  3. Use a constructor to initialize the attributes.
  4. Implement calculateInventoryValue() to multiply price by quantity.
  5. Create a separate InventoryApp class with main().
  6. Instantiate at least two Product objects.
  7. Display each product's details and calculated inventory value in the console.
  8. Use JOptionPane.showMessageDialog() to display a graphical summary.
  9. Use comments and consistent indentation.
  10. Push the completed application to GitHub.

Example: Product.java

public class Product {
    private String name;
    private double price;
    private int quantity;

    public Product(String name, double price, int quantity) {
        this.name = name;
        this.price = price;
        this.quantity = quantity;
    }

    public double calculateInventoryValue() {
        return price * quantity;
    }

    public String getName() {
        return name;
    }
}

Example: InventoryApp.java

import javax.swing.JOptionPane;

public class InventoryApp {
    public static void main(String[] args) {
        Product product1 = new Product("Laptop", 899.99, 5);
        Product product2 = new Product("Mouse", 25.99, 10);

        double total =
            product1.calculateInventoryValue() +
            product2.calculateInventoryValue();

        System.out.println("Inventory Value: $" + total);

        JOptionPane.showMessageDialog(
            null,
            "Total Inventory Value: $" +
            String.format("%.2f", total)
        );
    }
}

Extend the example: Display each product's name and individual inventory value in the console and GUI summary. The example above is a starting point, not the entire solution.

Discussion: Procedural vs. Object-Oriented Programming

50 points · Weeks 1–2

Topic: Why Does Object-Oriented Programming Matter?

Programming languages use different approaches to organizing instructions and data. Two common approaches are procedural programming and object-oriented programming. Java is primarily object-oriented, allowing developers to organize applications around classes and objects.

Initial Post (at least 250 words)

Address all five prompts:

  1. What is the difference between procedural programming and object-oriented programming?
  2. What advantages do classes and objects provide when developing larger applications?
  3. Explain encapsulation, inheritance, and polymorphism using real-world examples.
  4. Is object-oriented programming always the best approach? Why or why not?
  5. Describe a real-world application that would benefit from object-oriented programming.

Peer Responses

Respond to at least two classmates, with at least 100 words per response. Extend the conversation with meaningful feedback, a thoughtful question, or another example. Simple responses such as “I agree” or “Great post” will not earn full credit.
